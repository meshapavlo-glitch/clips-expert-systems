# Експертні системи на базі CLIPS
Репозиторій містить результати розробки баз знань та правил у середовищі CLIPS в рамках дисципліни «Інтелектуальні інформаційні технології».

## Автор
- Студент: Меша Павло
- Група: ІН-31/1

## Структура репозиторію
- `Lab1/` – операції з фактами (assert, retract, facts);
- `Lab2/` – створення шаблонів (deftemplate) та впорядковані факти;
- `Lab3/` – формування бази правил (defrule) експертної системи;
- `Lab4/` – створення та використання функцій (deffunction);
- `Lab5/` – дерева рішень та логічне виведення;
- `README.md` – опис проєкту.

## Висновки
У результаті виконання практичних завдань було:   
Створено публічний репозиторій clips-expert-systems для структурування та систематизації навчальних матеріалів із дисципліни «Інтелектуальні інформаційні технології».   
Сформовано чітку структуру проєкту із розділенням програмного коду CLIPS за тематичними папками Lab1–Lab5, що відображають етапи вивчення фактів, шаблонів (deftemplate), правил (defrule), функцій (deffunction) та розв'язання логічних задач.
Оформлено файл README.md мовою розмітки Markdown із зазначенням відомостей про автора, опису структури репозиторію та узагальнених підсумків розробки.   
Набуті навички роботи з GitHub дозволяють зручно зберігати історію розробки експертних систем, забезпечують цілісність коду та публічність результатів виконаної роботи.
